# 哔哩哔哩主题定制

Chrome / Edge 扩展，可设置本地背景图、毛玻璃或透明效果。弹窗采用 Windows 98 风格，支持中文和 English；首次打开时跟随浏览器语言，也可在弹窗中手动切换并保存。还可切换全元素或内容面板模式，调整玻璃浓度、模糊强度和点缀色。

## 安装

1. 打开 `chrome://extensions/` 或 `edge://extensions/`，开启开发者模式。
2. 点击“加载已解压的扩展程序”，选择本项目文件夹。
3. 打开或刷新哔哩哔哩网页，点击扩展图标设置主题。

项目根目录只有浏览器运行所需的 7 个插件文件和这份说明，无需 Node.js、npm 或构建步骤。修改文件后，在扩展管理页点“重新加载”，再刷新网页即可。

## 文件

| 文件 | 用途 |
| --- | --- |
| `manifest.json` | 扩展入口、权限和脚本清单 |
| `popup.html`、`popup.css`、`popup.js` | 设置弹窗 |
| `content.js` | 注入网页背景与玻璃样式 |
| `background.js` | 串行保存设置和图片、迁移旧版数据 |
| `settings.js` | 弹窗、网页脚本和后台共用的设置格式与通信代码 |

图片在弹窗中缩放并转换为静态 WebP，只保存到浏览器本地。同一个扩展更新到新版本时，原有设置与背景图会自动迁移。全元素毛玻璃可能增加渲染负担；如页面变慢，可降低模糊强度或改用内容面板模式。

全元素模式会清除页面容器的底色，毛玻璃加在导航、内容面板和站内弹窗上，避免多层模糊叠加到缩略图和播放器。未设置图片时使用深色渐变背景，方便阅读白色文字。

顶部导航的模糊使用独立背景层，鼠标悬停打开的菜单可以继续模糊导航后方的网页内容。毛玻璃模式下会取消顶部悬浮窗的淡入过渡，让模糊从弹窗出现时就生效。

启用主题后，网页文字统一显示为白色；内容面板使用深色半透明底色，搜索框等文字输入区域也会变暗，方便阅读。

视频简介和评论区使用同样的玻璃材质；评论组件的开放 Shadow DOM 会在加载后自动应用主题。评论列表的白色渐变遮罩、登录弹窗与输入框、搜索建议、下拉菜单和播放器菜单也会随主题调整。
