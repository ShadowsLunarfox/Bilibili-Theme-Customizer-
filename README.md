# 哔哩哔哩主题定制

Chrome / Edge 扩展，可设置本地图片、GIF 或 MP4 动态背景，以及毛玻璃或透明效果。弹窗采用 Windows 98 风格，支持中文和 English；首次打开时跟随浏览器语言，也可在弹窗中手动切换并保存。还可切换全元素或内容面板模式，调整玻璃浓度、模糊强度、点缀色和网页字体颜色，并按需隐藏部分按钮。

## 安装

1. 打开 `chrome://extensions/` 或 `edge://extensions/`，开启开发者模式。
2. 点击“加载已解压的扩展程序”，选择本项目文件夹。
3. 打开或刷新哔哩哔哩网页，点击扩展图标设置主题。

项目根目录只有浏览器运行所需的 6 个插件文件和这份说明，无需 Node.js、npm 或构建步骤。修改文件后，在扩展管理页点“重新加载”，再刷新网页即可。

若“隐藏本组”后计数仍停在 `0/N`，先看弹窗底部和扩展管理页的错误。旧后台会被弹窗识别并提示重新加载；后台无法启动时则会提示连接失败。更新文件后，需要在扩展管理页重新加载插件，再刷新已打开的哔哩哔哩标签页；仅关闭并重新打开设置弹窗不会更新后台和网页脚本。若扩展页仍提示 `settings.js` 加载失败，请检查已解压扩展的来源文件夹是否仍是当前项目文件夹。

## 文件

| 文件 | 用途 |
| --- | --- |
| `manifest.json` | 扩展入口、权限和脚本清单 |
| `popup.html`、`popup.css`、`popup.js` | 设置弹窗 |
| `content.js` | 注入网页背景与玻璃样式 |
| `settings.js` | 共用设置格式、通信代码，以及扩展后台的串行保存和旧版数据迁移 |

背景文件最大为 20 MB。静态图片会在弹窗中缩放并转换为 WebP；GIF 保留动画，MP4 在网页和预览中静音循环播放，网页标签页不可见时会暂停。文件只保存到浏览器本地，扩展使用 `unlimitedStorage` 权限容纳 20 MB 文件。同一个扩展更新到新版本时，原有设置与背景图会自动迁移。全元素毛玻璃可能增加渲染负担；如页面变慢，可降低模糊强度或改用内容面板模式。

全元素模式会清除页面容器的底色，毛玻璃加在导航、内容面板和站内弹窗上，避免多层模糊叠加到缩略图和播放器。未设置图片时使用深色渐变背景，方便阅读白色文字。

顶部导航的模糊使用独立背景层，鼠标悬停打开的菜单可以继续模糊导航后方的网页内容。毛玻璃模式下会取消顶部悬浮窗的淡入过渡，让模糊从弹窗出现时就生效。

启用主题后，网页文字默认显示为白色，可在弹窗里选取其他颜色。输入框会根据字体明暗切换底色。内容面板使用半透明底色。

“导航与按钮”按顶部左侧、首页频道图标、频道分类、快捷入口、更多频道和其他控件分类。顶部右侧的隐藏选项已移除，原先保存的右侧隐藏设置也不再生效。其余导航入口保留独立开关；同一个频道在首页和滚动后的固定导航会一起隐藏。每组标题旁可一键隐藏或显示本组，分类顶部也可一键隐藏或显示全部。频道图标、分类或快捷入口全被隐藏时，各自的占位会收起；三组都隐藏时，首页频道行和滚动后的固定频道行会整体收起。开关默认关闭，原先已开启的“隐藏顶部下载”设置会自动保留；关闭主题或取消勾选即可恢复按钮。

视频简介和评论区使用同样的玻璃材质；评论组件的开放 Shadow DOM 会在加载后自动应用主题。评论列表的白色渐变遮罩、登录弹窗与输入框、搜索建议、下拉菜单和播放器菜单也会随主题调整。
